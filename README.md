# TubeMaster

Gestionnaire de liens YouTube pour Windows, en C++17 (SDL2, OpenGL 3.3, Dear ImGui, libcurl, Edge WebView2) :
listes importées et triées, lecteur YouTube intégré, export MKV / MP4 / MP3 (yt-dlp + ffmpeg),
recherche d'origine des liens morts (Wayback Machine, Filmot…).

Mode d'emploi : [LISEZMOI.txt](LISEZMOI.txt).

Compilation (exécutable Windows depuis Linux, llvm-mingw) et essai réel sous Windows :
voir `.github/workflows/tubemaster.yml` (résultats sur la branche `essais`).
